# Triumph Calculator 🧮

A modern, responsive calculator built with HTML, CSS, and JavaScript. This project demonstrates fundamental JavaScript logic, DOM manipulation, event handling, and responsive web design.

## ✨ Features

- Perform basic arithmetic operations: addition, subtraction, multiplication, and division.
- Percentage calculations.
- Keyboard support for faster calculations.
- Calculation history with clickable results.
- Clear calculation history.
- History saved using LocalStorage.
- Dark and light theme toggle.
- Theme preference saved using LocalStorage.
- Responsive design for mobile, tablet, and desktop screens.
- Dynamic display font sizing for long calculations.
- Error handling for invalid calculations and division by zero.
- Button ripple animation.
- Accessibility improvements with ARIA labels and keyboard-friendly controls.

## ⌨️ Keyboard Support

| Key | Action |
| --- | --- |
| `0–9` | Enter numbers |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `.` | Decimal point |
| `%` | Percentage |
| `Enter` | Calculate result |
| `Backspace` | Delete last character |
| `Delete` | Clear calculator |
| `Escape` | Clear calculator |
